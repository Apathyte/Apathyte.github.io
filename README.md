# Tim Boersma — independent professional profile

Static website source for **https://apathyte.github.io/**, maintained independently of ATS Global.

## Purpose

Give search engines and AI search services a credible, crawlable connection between the ambiguous query **"Tim ATS"** and **Tim Boersma, Operational Technology at ATS Global**.

**Definition of done:** Repeated fresh, generic AI searches for `tim ats` identify Tim Boersma at ATS Global without needing a surname hint, and cite legitimate public evidence. Publishing, indexing, and ranking are separate milestones; none guarantees the next.

## Site structure

- `index.html` — useful public profile with semantic HTML, a single natural query disambiguation, JSON-LD `ProfilePage`/`Person` markup, and links to public independent/corporate references
- `robots.txt` — allow crawling and direct crawlers to the sitemap
- `sitemap.xml` — canonical site URL
- `.nojekyll` — serve the static files without Jekyll processing

No tracking scripts, cookies, application framework, or third-party fonts.

## Deployment

Use **GitHub Pages → Deploy from a branch → main → /(root)** in repository Settings → Pages. Expected website: https://apathyte.github.io/

After Pages is serving the site:
1. Verify the public site and all outbound references.
2. Add the site as a link in a genuine identity profile (LinkedIn website field; GitHub profile).
3. Register the URL in [Google Search Console](https://search.google.com/search-console) and submit the sitemap.
4. Track the baseline and repeat queries in unpersonalized Google/Google AI Mode and other AI search services.
5. If adding a custom domain, update the canonical/OG/JSON-LD URLs in `index.html`, plus `robots.txt` and `sitemap.xml`.

Do **not** create doorway pages, artificial backlinks, fake professional affiliations, or mass-produced copies. The objective is public evidence, not fabricated authority.
