# Learning studio — design direction

Approved programme, 10 November 2026. Implementation decisions belong to the
approved scope; no new aesthetic sign-off is required.

First teaching question: when eligible material is short, who can resequence,
authorise a substitute or stop the start? Physical availability is not eligibility.
All cases are original fictional examples, with no real process values or layouts.

Considered a larger purple card, an entirely light app, and a dark model workspace
paired with a warm light narrative. Selected the third. Violet retains brand and
selection; paper/ink provides reading hierarchy and projection contrast. System
fonts avoid external requests. Monospace is reserved for IDs and signals.

Desktop: lesson/scope controls, comparison, model left and narrative right, then
boundary register and optional facilitator prompts. Narrow screens put the story
first and stack the model underneath. Presentation mode removes peripheral chrome
and retains a visible exit control. All actions remain keyboard reachable.

Material: solid amber arrows. Events: dashed cyan arrows. Authority: dotted violet
arrows. Each has a text legend and endpoint register; colour is not the only cue.
Authority edges describe approvals, not network routes. A constrained material
handover is red/dashed and explicitly named in the register.

Comparison retains geometry, selection and viewpoint. Only assumptions and state
annotations change; proposed consequences are hypothetical, not measured savings.
Camera follows stages by default; manual selection pauses follow. Overview and
reduced-motion support keep the presenter in control. SVG fallback offers the same
selection and focus; GPU acceptance must be verified separately.

Six-stage story: situation, reference, disruption, response, consequences, evidence.
A response must be selected before consequences. Every choice names authority,
material/information/people effects and residual risk. Unsafe shortcuts are
explicitly rejected. The last stage asks what evidence would justify a real claim.

## Finding during implementation

A bounded response must not turn a held material path green. Replanning while a
lot is held can be appropriate, but the original lot still cannot move to packing.
The proposed comparison therefore retains the blocked handover and says its
prerequisites are unverified. Only the explicit reference view assumes readiness.
This avoids treating “reasonable decision” as “completed and accepted action”.
